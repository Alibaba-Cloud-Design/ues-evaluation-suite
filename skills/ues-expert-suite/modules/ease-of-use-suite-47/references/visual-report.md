# 易用性可视化扩展

先读取已安装 `ues-expert-suite` 的 `references/visual-report-system.md`，该文件是全局样式、信息架构和组件的唯一规范。本文件只定义易用性专项内容，不能改变47条准则、证据门槛或计分。

- 总览：易用性基准分与评级；dual模式并列场景参考分和差值；易见性、易学性、易操作性统一0–10横条；page与flow覆盖分开。
- 任务插槽：URL/Demo显示 `入口 → 操作 → 即时反馈 → 结果 → 恢复/继续`；单张截图显示证据边界，不画伪流程。
- 整改优先级：按High→Major→Minor→Advisory；标签使用“易用性 · 维度 · 准则ID”；同根因只出现一次，全部命中准则列在同卡。
- 范围与方法：47条完整判断、置信度、场景画像、权重策略、证据不足和未验证范围。
- 场景参考分不赋正式评级，也不取代基准分。
- 默认可查看全部47条，逐条区分通过、部分通过、失败、证据不足与不适用；不得用“有问题”合并状态，也不得只列扣分项。

问题图片、红框、原图灯箱、导出链接和响应式行为全部服从共享规范。没有真实导出文件时不显示导出控件。

## v0.3 独立检查展示

当前日常检查以“基础体验与风险检查”命名，禁止出现笼统的“基线不通过”主结论。逐条pass/fail/not_verified/N/A保留，not_verified中文为“未验证”，范围外另列，绝不并入失败。全局findings_status和verification_status分开显示；如无事前发布规则，发布状态为“未评估”，不作发布许可推断。

无障碍归入基础体验与风险检查BL-04，可展开细项；不生成独立分数、卡片或专项。
