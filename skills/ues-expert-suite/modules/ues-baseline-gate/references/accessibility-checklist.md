# BL-04 无障碍检查细项

此12组覆盖常见基础风险，非完整WCAG 2.2 A/AA清单。正式符合性审计须逐条核验全部适用成功准则和符合性要求。以下WCAG编号是参考关系，不意味着一个集合项通过即满足所有相关准则。

来源：[W3C WCAG 2.2 快速参考](https://www.w3.org/WAI/WCAG22/quickref/)（2026-09-11核对）。查具体阈值、例外和适用性时读取其对应Understanding条目，不凭简表忽略例外。

| ID | 检查组 | 验证要点与最小证据 | WCAG参考 |
|---|---|---|---|
| BL-04.01 | 文字与非文字对比 | 在实际前景/背景及适用状态测量对比值；检查适用阈值和例外。截图肉眼观感不能替代测量。 | 1.4.3、1.4.11 |
| BL-04.02 | 非文本替代与非颜色线索 | 图片/图标替代文本、装饰跳过；状态和错误不只靠颜色；视觉与辅助树对照。 | 1.1.1、1.4.1 |
| BL-04.03 | 缩放、重排与文字间距 | 实测200%文字缩放、320 CSS px重排及文字间距调整；保留适用例外。390px正常不能证明320px重排合格。 | 1.4.4、1.4.10、1.4.12 |
| BL-04.04 | 键盘可操作与无陷阱 | 冻结核心路径上的控件逐项Tab/操作/退出，含弹层；截图或部分控件Enter有效不足以判整组通过。 | 2.1.1、2.1.2 |
| BL-04.05 | 焦点可见、顺序与不被遮挡 | Tab及弹层前后轨迹、焦点轮廓/位置和固定元素遮挡；一处焦点不可见可fail，其余缺口另记。 | 2.4.3、2.4.7、2.4.11 |
| BL-04.06 | 名称、角色、值和状态 | 控件与复合组件的可访问名称/角色/选中状态/面板关系；比对DOM与辅助树，必要时用辅助技术验证。 | 4.1.2 |
| BL-04.07 | 结构、导航与语言 | 页面标题、标题层级、区域、表格关系、跳过重复区块、页面语言；检查DOM和实际导航。 | 1.3.1、2.4.1、2.4.2、3.1.1 |
| BL-04.08 | 表单标签、说明与错误关联 | 输入目的、可见标签与可访问名称、约束、错误定位与修复说明；实际触发适用输入错误。 | 2.5.3、3.3.1、3.3.2、3.3.3 |
| BL-04.09 | 动态状态与反馈可感知 | 搜索加载、结果数、错误/成功等适用反馈；实际触发并核验辅助技术播报，不能只凭aria-live存在判通过。 | 4.1.3 |
| BL-04.10 | 指针、拖拽与目标尺寸 | 测量触控目标及间距/例外；需要复杂手势或拖拽时检查简单指针替代和取消。 | 2.5.1、2.5.2、2.5.7、2.5.8 |
| BL-04.11 | 媒体、动效与时限控制 | 按实际存在的音视频、自动运动、闪烁、计时内容分别检查替代/字幕与暂停、时间调整及闪烁限制；无媒体不等于无动效。 | 1.2.1–1.2.5、1.4.2、2.2.1、2.2.2、2.3.1 |
| BL-04.12 | 可预期操作与可访问认证 | 检查焦点/输入不意外改变上下文；若有登录，检查认知测试替代及粘贴等辅助机制。范围内存在而未授权登录记未验证。 | 3.2.1、3.2.2、3.3.8 |

每组适用子要求全证才pass，有违反则fail并记录remaining_gaps，否则not_verified。所有子条件正面确认不存在才可整组N/A。既有证据迁移可以只形成某个fail而让其他组未验证，不把已知障碍抹掉，也不将未覆盖视为失败。

本清单仅细化BL-04，无独立分数或80%出分门槛。原AX编号只作历史映射，当前用BL-04.01～BL-04.12。子项不能当成12条新增顶层准则或再次扣分。
