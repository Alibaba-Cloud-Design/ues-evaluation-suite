# 简易任务分可视化扩展

先读取已安装 `ues-expert-suite` 的 `references/visual-report-system.md`，该文件是全局样式、信息架构和组件的唯一规范。本文件只定义任务专项内容。

- 总览：显示“简易任务分”、证据等级、最终分与评级；AEM模式必须使用自身正式名称。
- 任务插槽：每个任务卡显示角色、目标、入口、成功真值、正常/边界/恢复场景、步骤链、结果和分数。
- 整改优先级：卡点按Gate→Major→Minor→Advisory，标签使用“简易任务 · 任务/步骤 · 准则ID”；影响完成与否明确写出。
- 范围与方法：展示E_lite、P_lite、Q、原始分、上限和最终分，以及20条完整判断与证据。
- 不把冻结场景的简易完成率写成线上真实用户完成率。
- 默认可查看全部20条准则；多任务评估按任务分别保留每条判断，不把不同任务压成一个状态，也不只列卡点准则。

任务截图、红框、轨迹证据和灯箱全部服从共享规范。

## v0.3 独立检查展示

当前日常检查以“基础体验与风险检查”命名，禁止出现笼统的“基线不通过”主结论。逐条pass/fail/not_verified/N/A保留，not_verified中文为“未验证”，范围外另列，绝不并入失败。全局findings_status和verification_status分开显示；如无事前发布规则，发布状态为“未评估”，不作发布许可推断。

无障碍归入基础体验与风险检查BL-04，可展开细项；不生成独立分数、卡片或专项。
