# 简易性能与正式性能可视化扩展

先读取本技能随附的 `references/visual-report-system.md` 和 `references/dashboard-report.md`，使用本技能的 `assets/report-kit/`（与总入口同版），该文件是全局样式、信息架构和组件的唯一规范。本文件只定义性能专项内容。

- 合成或单次PCP显示为“简易性能分”，并紧邻显示“预上线合成 PCP”或“Reporter 单次实测”来源；正式监控聚合值显示“正式线上性能分”。
- 总览：PCP毫秒值、0–10分、评级、数据源、聚合方式、样本数和误差/波动。
- 测量插槽：同尺度显示 `前一未完成帧 → 首个完成帧 → 稳定确认帧`，写明完成规则与时间戳。
- 整改优先级：只有证据支持优化问题时才建立问题卡；不能从一个总时长猜测具体资源或代码根因。
- 范围与方法：展示分段公式、代入值、全精度结果、展示分、缓存/网络条件和局限。
- FCP/LCP/TTFB/模型响应时延只能放在诊断区，不进入PCP公式。
- 默认完整展示测量合同、前后帧、完成规则、样本、误差、公式和限制；性能没有固定准则库，不得为了与其他专项对齐而伪造pass/fail准则行。

电影条图片、红框、原图灯箱和响应式行为全部服从共享规范。

## v0.3 独立检查展示

当前日常检查以“基础体验与风险检查”命名，禁止出现笼统的“基线不通过”主结论。逐条pass/fail/not_verified/N/A保留，not_verified中文为“未验证”，范围外另列，绝不并入失败。全局findings_status和verification_status分开显示；如无事前发布规则，发布状态为“未评估”，不作发布许可推断。

无障碍归入基础体验与风险检查BL-04，可展开细项；不生成独立分数、卡片或专项。
