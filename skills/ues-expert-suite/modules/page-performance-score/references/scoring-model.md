# PCP 性能分口径

## 输入变量

`p` 为 PCP 毫秒值，必须是非负有限数。不同单位必须先转换为毫秒。

只有明确为 PCP 的值，或按本 Skill 完成状态合同测得并标为 `synthetic_lab` 的预上线合成 PCP，才能进入本公式。FCP、LCP、DCL、FSP、`load`、接口耗时或任务耗时都不是 PCP。

## 分段公式

\[
S(p)=
\begin{cases}
10, & 0 \le p \le 1000 \\
10-\frac{p-1000}{250}, & 1000 < p \le 1500 \\
8-\frac{p-1500}{500}, & 1500 < p \le 5500 \\
0, & p > 5500
\end{cases}
\]

计算结果限制在 `[0,10]`。中间计算保留全精度，报告展示一位小数。

### 边界校验

| PCP | 分数 |
|---:|---:|
| 0ms | 10.0 |
| 1000ms | 10.0 |
| 1250ms | 9.0 |
| 1500ms | 8.0 |
| 2800ms | 5.4 |
| 5500ms | 0.0 |
| 5501ms | 0.0 |

## 评级

- `[0,5)`：差
- `[5,7)`：中
- `[7,8.5)`：优
- `[8.5,10]`：卓越

边界按左闭右开执行，10 分包含在“卓越”。

## 结果类型

### 正式线上性能分

同时满足：

- PCP 来自组织性能平台、官方数据接口或可审计导出；
- 能定位产品、环境和页面/路由或者明确的产品聚合对象；
- 能说明统计窗口与聚合方式；
- 数值单位已验证为毫秒。

样本数缺失不会自动把数字变成单次实测，但必须标记“样本充足性未验证”。参考接入文档将 2000 作为样本量参考，它不是本公式的通用硬门槛；低于该值时应显示低样本波动风险。

### 单次实测性能分

PCP 来自当前浏览器页面一次导航中的 reporter 回调。必须同时显示：

- 浏览器/设备与网络条件（能获取多少写多少）；
- 冷/热缓存是否受控；
- 获取时间和页面 URL/路由；
- “本值不代表线上用户分布”。

可使用同一公式换算分数，但分数名称不得省略“单次实测”。

### 预上线合成 PCP 性能分

同时满足：

- 产品至少达到预上线阶段，并有稳定、可重复访问的 URL；
- 从文档导航开始前计时；
- 预先声明当前路由“主要界面已渲染”的可见条件与排除项；
- 保存首个稳定合格帧及其前序状态证据；
- 展示环境、缓存、视口、采样间隔和该次原始测量值。

使用本页同一公式评分。默认只测量 1 次并直接使用该次 PCP，名称必须保留“单次预上线合成 PCP”，同时注明“波动未知，不代表线上真实用户分布”。只有用户明确要求时才增加测量次数。

### PCP未评分（不等于简易网页性能未评分）

任一情况下不给 PCP 分：

- 只有截图、视频或主观感受；
- 页面没有 PCP reporter 和聚合数据，且不适用或无法满足预上线合成测量合同；
- 只拿到 LCP/FCP/加载时间；
- 返回了对象，但无法确认哪个数字字段是 PCP 毫秒值；
- 数据口径冲突且没有权威源可供确认。

对于已达到预上线阶段的页面，“没有 reporter”本身不再构成无法评分；只有合成测量合同也无法满足时才不给分。早于预上线阶段记“不适用”，不计 0 分。

## 聚合口径约束

P50/中位数、P75 和算术平均值不可互换。如果上游平台已给出标准 PCP，直接消费该值并保留上游标签。

如果只有原始样本：

1. 先获得组织确认的窗口、分位数/平均方式、排除规则和产品/路由粒度；
2. 口径缺失时可以输出 P50/P75/均值的并列敏感性结果，但不得任选一个称为正式分；
3. 不对不同窗口、环境、产品或路由的数据做隐式合并。

## 产品级聚合

单页/单路由分数可直接报告。多路由结果默认仅列表，不做算术平均。

只有用户提供官方聚合 PCP，或提供路由权重与聚合规则时，才输出产品级数值。不先平均各路由分数再写成“官方产品分”。


## PCP不可得时的后续路由

上述未评分条件只决定PCP路径。对于预上线或线上网页的性能评估，还须执行 [simple-web-performance.md](simple-web-performance.md) 的适用性与能力检查，满足条件就测量并计算独立的简易性能分。只有PCP和简易路径均不可用才整体未评分。纯已有记录核验或明确禁止新采样的请求不扩展。简易visible_first_view_ms不能放入PCP字段或标为正式线上聚合。
