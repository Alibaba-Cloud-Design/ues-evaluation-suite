# 简易网页性能回退

当本专项或宽泛 UES 评估对象是可运行网页，且已达到预上线或线上阶段时，性能默认进入自动路由。先按 `page-performance-score` 判断正式 PCP 是否适用；不适用或无法取得合法 PCP 时，只要可以安全地执行受控导航并定义可复核的首屏完成状态，就自动执行本回退，不等待用户提出“简易性能”或再次确认。

## 适用条件

同时满足：

- 输入是可运行网页 URL 或可导航 Demo；
- 阶段为预上线或线上，或证据足以推定为其中之一；
- 可在不提交业务数据、不产生购买或资源变更的前提下执行一次导航；
- 能从可见界面定义首屏完成标志。

静态截图、设计稿、不可运行原型、开发早期页面和无法可靠观察导航起点的环境不评分，报告说明缺失条件。

## 导航前准备（必经）

先执行 [performance-capture-preflight.md](performance-capture-preflight.md)。正式导航不得先于采集armed确认；测量完成后立刻验收，合格才计分。仅操作后截图不满足采集能力；当场记录blocked并告知，而不是走查结束后补写缺口。

## 默认测量

默认执行一次受控导航。计时从导航动作发出前开始，到首个同时满足下列条件并稳定至少 100ms 的状态结束：

1. 页面用途可由标题或主标题唯一识别；
2. 主导航或主要行动入口可见；
3. 首个主要内容区不再是空白、骨架或占位文本；
4. 没有覆盖首屏主体的持续加载层。

冻结条件时明确区分主要内容与辅助动作。只有会阻碍页面用途、主行动或首个主要内容识别的对象才进入完成门；登录、客服、次级推荐等辅助对象若不影响当前任务，不得拖延完成时间。人工复核必须记录最后未完成帧、首个完成帧和至少100ms后的稳定帧，完成边界不确定度取前两帧的时间差。

记录 `visible_first_view_ms`、样本数、视口、缓存/网络已知条件、完成标志、稳定判定和证据截图。无法确认缓存或网络条件时写 `unknown`，不得假设。

## 简易性能分

令 `v` 为 `visible_first_view_ms`：

```text
10                              0 <= v <= 1000
10 - (v - 1000) / 250          1000 < v <= 1500
8 - (v - 1500) / 500           1500 < v <= 5500
0                               v > 5500
```

结果限制在 0–10，保留内部精度并展示一位小数。评级为：低于5“差”，5至低于7“中”，7至低于8.5“优”，8.5至10“卓越”。使用 `scripts/calculate_simple_web_performance_score.mjs --visible-ms <毫秒>` 复算。

联合报告名称固定为“简易性能分”，并写明“单次可识别首屏”、样本数和限制。它不是 PCP、LCP、FCP 或真实用户分布。单项调用只输出性能结果，不启动其他专项；联合评估时，若易用性、任务和一致性也有合法0–10基准分，则由总入口计算简易 UES 综合分。

先人工核验原始样本，再运行计分脚本得到候选分数并写入performance-capture.json；随后运行性能产物校验器，通过后才能交付分数。仅在联合评估时按 [performance-capture-preflight.md](performance-capture-preflight.md) 的“报告联动检查”一次性更新基线、联合问题、总览、方法说明和交付包。

## 已登录业务页与采样对象

沿用用户明确授权的已登录会话，不默认要求隔离临时会话。自带采集器创建的是空白临时Chrome配置，不继承登录态；不能将其中的登录页当作目标业务页。当前工具不能在授权会话中进行导航前采集时，记录回退取证阻断，不复制Cookie、令牌或用户配置来解决。可使用工具明确允许且保留授权会话的其他采集方式；不得绕过浏览器工具限制。

冻结精确业务路由、地域、视口和完成条件。实例列表为0条不必等待出现实例：已确认加载结束、列表标题与控件可见并出现真实空状态，可以满足事前定义的首屏完成条件。骨架、错误页或登录页不能代替目标业务空状态。若正式导航发生跳转或路由未匹配，样本不进入该业务页计分。

SPA路由需明确本次是对目标URL的一次受控文档导航；不能用/home的Reporter或其他导航样本给实例路由计分。原场景限定软导航且工具无法测量时保留限制，不悄悄改变测量对象。每条路径分别报告：PCP来源状态及原因、简易采集状态、最终指标和分数。
