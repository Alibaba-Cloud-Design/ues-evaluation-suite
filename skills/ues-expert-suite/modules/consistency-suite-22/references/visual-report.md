# 一致性可视化扩展

先读取已安装 `ues-expert-suite` 的 `references/visual-report-system.md`，该文件是全局样式、信息架构和组件的唯一规范。本文件只定义一致性专项内容，不能改变22条准则、比较组、风险上限或发布判断。

- 总览：输入证据等级、运行模式、`原始分 → 风险上限 → 最终分`、历史参考档位、发布结论、page/flow与基准覆盖。
- 比较插槽：用 `比较组 × 页面/状态/视口 × 实际表达` 矩阵展示规范、产品模式、暂定基准和离群实例；不使用雷达图。
- 整改优先级：按Gate→Major→Minor→Advisory；标签使用“一致性 · 维度/基准类型 · 准则ID”；正确基准和问题实例与同一问题卡绑定。
- 范围与方法：22条完整判断、0–4量级、置信度、是否计分、linked_to、基准来源及证据不足。
- 风险上限导致最终分下降时，首屏必须解释触发问题，不能只显示低分。
- 默认可查看全部22条，逐条区分通过、部分通过、失败、证据不足与不适用，并显示是否参与计分；不得只列离群或扣分项。

问题图片、左右对比、红框、原图灯箱、导出链接和响应式行为全部服从共享规范。

## v0.3 独立检查展示

当前日常检查以“基础体验与风险检查”命名，禁止出现笼统的“基线不通过”主结论。逐条pass/fail/not_verified/N/A保留，not_verified中文为“未验证”，范围外另列，绝不并入失败。全局findings_status和verification_status分开显示；如无事前发布规则，发布状态为“未评估”，不作发布许可推断。

无障碍归入基础体验与风险检查BL-04，可展开细项；不生成独立分数、卡片或专项。
