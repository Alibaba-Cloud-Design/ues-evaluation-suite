# 旧UES/Xconsole一致性口径迁移

本文只在需要解释历史分数、旧自查表、Multi版两两比较法或旧一致性走查skill时读取。日常执行22条新准则不需要加载本文。

## 保留的核心思想

- Xconsole/控制台口径：产品实现与当前设计规范比较，对应 `spec_alignment`。
- UES一致性Multi版：产品内部可比页面与实例两两比较，对应 `self_consistency`。
- 规范覆盖与产品内部比较并存，对应 `hybrid`。
- 总分保留“不达标率50% + 加权缺陷严重性50%”的聚合理念。
- 旧0–4问题量级保留，但必须受pass/partial/fail rubric约束。

## 不再直接保留的内容

- 旧26条、50条或自定义14条不再作为新skill的主准则库。
- 特定组件名、旧版本固定像素值和旧平台专属条款，只有在用户将其指定为当前有效产品规范时才作为基准。
- 没有真实样本校准的CV 0.05、重叠度0.85、70/30页面与跨页加权等旧走查skill自定阈值不进入正式评分。
- `pending` 改为 `insufficient_evidence`，并进入覆盖声明。
- 不强制每个问题生成三张图；只在定位、比较或理解差异确实受益时生成。

## 旧14条关系规则到新22条

| 旧规则 | 主要新准则 | 迁移说明 |
|---|---|---|
| R1 同类元素表征收敛 | B04.01、B04.07、B04.08、B04.09、B04.16 | 拆分结构/尺寸、文字、间距、边框规则和体系外控件，不再使用一个统一离散度阈值。 |
| R2 同职责区域布局收敛 | B04.12、F6.02 | page评同角色区块，flow评同类步骤与行动区。 |
| R3 应区分者不可混淆 | B04.01、B04.04、F6.05、F6.08 | 变为“同类收敛 + 状态映射 + 显著差异理由”的证据化判断。 |
| R4 同信息层级表征一致 | B04.07、B04.12、B04.15、F6.02 | 按文字角色、区块骨架、跨区域语言和流程步骤分别取证。 |
| B1 同类操作反馈方式一致 | B04.05、F6.03、F6.04、F6.05 | 页面模式、跨状态组件反馈、交互容器和状态映射分开判断。 |
| B2 状态变化有信号与终态 | B04.04、F6.03、F6.05、F6.06 | 必须有运行或有序状态证据，静态截图不得推断。 |
| B3 破坏性操作处置方式一致 | B04.05、F6.04、F6.05、F6.08 | 一致性仅判同类风险的处置模式与映射；是否提供足够防护属于易用性/风险审查。 |
| B4 同条件下行为可预测 | F6.01、F6.03、F6.04、F6.05 | 通过对象/状态模型、组件行为、交互模式和语义映射判断。 |
| I1 同一意图呈现跨实例收敛 | B04.12、F6.02、F6.04 | 改为可定位的布局骨架、步骤区域和交互模式。 |
| I2 优先级与视觉权重一致 | B04.07、B04.12、F6.02、F6.08 | 本维度只评同类优先级的呈现是否稳定；“优先级本身是否正确”属于易用性。 |
| I3 同一语义符号全局一致 | A01.08、F6.01、F6.05 | 命名、对象/状态模型和颜色/图标/文字映射分开取证。 |
| A1 AI主体身份可辨且稳定 | F6.01、F6.05 | AI不再是自动触发的独立类；作为对象身份与语义映射的具体产品实例。 |
| A2 AI生成结果硬约束收敛 | B04.12、F6.03、F6.08 | 只在用户要求比较多次生成时作为扩展场景；不是22条核心准则的独立条目。 |
| A3 AI自主行为可理解有边界 | F6.01、F6.04、F6.08 | 只评估同类自主行为的语义、模式和差异理由；完整自主性风险审计需要另行范围。 |

## 旧层次到新准则

| 旧层次 | 新准则范围 |
|---|---|
| 物理层：看起来一样 | B03.01、B03.02、B04.01、B04.07、B04.08、B04.09、B04.12、B04.13、B04.15、B04.16 |
| 行为层：用起来一样 | B04.04、B04.05、F6.02、F6.03、F6.04、F6.06 |
| 认知层：形成统一认知 | A01.08、A02.03、F6.01、F6.05、F6.07、F6.08 |

该映射只用于历史沟通；一条新准则可以有多个旧来源，不代表评分时应重复计算。

## 分数迁移

旧口径中不达标率与缺陷严重性各50%的思想保留，但新公式显式将重要性与0–4量级归一化，并用当前适用且证据充分的计分项作为分母。详见 [scoring-model.md](scoring-model.md)。

新旧准则数量、重要性分布和证据要求均已变化，因此不得声称新分数与旧报告具有绝对直接可比性。需要历史连续性时：

1. 选取10–20个有旧分数和原始问题的产品样本；
2. 在相同页面、版本和任务范围下用新22条复评；
3. 比较总体排序、分数差和原严重问题的保留率；
4. 根据样本分布决定是否继续使用7/8/9历史参考档位。

校准完成前，新报告将档位标为“历史参考档位”，并将发布结论与档位分开。
